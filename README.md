# 直播录制器 iOS App

自动检测主播上线并自动录制直播源的 iOS 应用。

## 功能特点

- 支持抖音、快手、B站、虎牙、斗鱼五大平台
- 输入主播号/房间号自动检测上线
- 自动录制直播源（FLV格式，默认原画/最高画质）
- 自动获取主播名字
- 支持手动立即录制
- 录制文件管理和播放
- 后台录制支持

## 使用方法

1. 点击右上角 + 添加主播
2. 选择平台，输入主播号/房间号
3. 点击"开始监控"
4. 主播上线后自动开始录制
5. 在"录制文件"页面查看和播放录制的视频

## 技术栈

- SwiftUI
- URLSession 网络请求
- 后台下载录制
- AVPlayer 视频播放
